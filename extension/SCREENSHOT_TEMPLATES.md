## Screenshot Requirements
- Resolution: 1280x800 pixels
- Format: PNG
- Number of screenshots: 5 (minimum), 8 (recommended)
- File naming: screenshot-1.png, screenshot-2.png, etc.

## Design Guidelines

### Colors
- Background: #0A0A0F (dark)
- Card Background: #12121A
- Border: #1E1E2E
- Accent: #6C63FF (purple)
- Text: #F0F0FF (primary), #8888AA (secondary)
- Success: #10A37F (green)
- Error: #FF4444 (red)

### Typography
- Font: -apple-system, BlinkMacSystemFont, 'Segoe UI', sans-serif
- Headings: Bold, 600-700 weight
- Body: Regular, 400 weight
- Labels: Uppercase, 600 weight, letter-spacing 0.5px

### UI Elements
- Rounded corners: 8px (small), 12px (medium), 16px (large)
- Shadows: 0 4px 12px rgba(0,0,0,0.3) (small), 0 8px 24px rgba(0,0,0,0.4) (large)
- Hover states: Border color change to #00D4FF or background darkening

### Platform Colors
- Claude: #CC785C (terracotta)
- ChatGPT: #10A37F (green)
- Gemini: #4285F4 (blue)
- Grok: #FFFFFF (white)
- Perplexity: #20B2AA (teal)

## Tips for Creating Screenshots

1. **Use real data** - Create sample projects and checkpoints for authentic look
2. **Clean browser** - Hide browser chrome, bookmarks, and extensions
3. **Consistent theme** - Ensure dark theme is applied throughout
4. **High resolution** - Use 1280x800 or higher for crisp images
5. **No personal info** - Remove any real emails, API keys, or sensitive data
6. **Show variety** - Demonstrate different features across screenshots
7. **Professional polish** - Ensure UI elements are properly aligned and styled

## Tools for Screenshot Creation

- **Chrome DevTools** - Device toolbar for responsive screenshots
- **CleanShot X** - For Mac users, professional screenshot tool
- **Snagit** - Cross-platform screenshot and annotation tool
- **Figma** - Can create mockups if real screenshots aren't ready
